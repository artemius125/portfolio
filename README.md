## Стек

**Языки и рантайм:** Python 3.10+ (async/await), в контейнерах 3.12. Немного JS для
встраиваемых виджетов.

**Веб:** FastAPI, Starlette, SSE-стриминг, Flask и HTMX там, где не нужен SPA,
server-rendered Jinja2-админки вместо фронтенд-сборки.

**Данные:** PostgreSQL, SQLAlchemy 2.x (async, asyncpg и psycopg 3), Alembic-миграции,
JSONB, частичные индексы, upsert-идемпотентность, advisory-локи, ретеншн-политики.

**LLM:** OpenAI-совместимые API и провайдеры OpenAI, Anthropic, Gemini, DeepSeek. Function
calling, JSON-режим и guided decoding по схеме, стриминг, агентные циклы с ограничением
шагов, LLM-as-judge, пакетная офлайн-разметка под бюджетом. Учёт токенов и стоимости как
продуктовая функция.

**Поиск и ранжирование:** field-weighted BM25 с IDF и нормализацией длины, лёгкий стемминг
для русского, косинусный поиск по эмбеддингам на numpy, каскадные скоринговые пайплайны с
объяснимым разложением риска.

**Инфраструктура:** Docker, Kubernetes (реплики, RollingUpdate, пробы, requests/limits,
nodeSelector, tolerations), Helm, GitLab CI и GitHub Actions, Loki и Grafana для логов,
Prometheus, Sentry.

**Документы и форматы:** python-docx, openpyxl, python-pptx, pypdf, reportlab, Pillow,
LibreOffice как конвертер, OCR сканов под бюджетом страниц. Приёмка артефактов независимыми
парсерами, а не инструментами самого продукта.

**Межсервисное:** gRPC с protobuf-контрактами, JSON Schema и Pydantic на границах, ключи
идемпотентности на шаг.

**Инженерная гигиена:** pytest с фейковыми LLM-клиентами (сеть в тестах не нужна),
golden-тесты и eval-харнессы с ассертами на метрики, приёмочные корпуса из реальных
документов с проверяемым провенансом (sha256 в манифесте), fail-closed конфигурация,
санитайзинг секретов в логах, обезличивание персональных данных в датасетах, ruff и mypy.

## Как устроен каждый кейс

Коротко на пять строк, затем: задача и ограничения, диаграмма архитектуры, стек, инженерные
решения с альтернативами и их ценой, что было сложно (настоящие баги и инциденты), результат,
моя роль. Метрики приводятся только там, где их подтверждают код, конфигурация или замеры.
Где чисел нет, так и написано.
